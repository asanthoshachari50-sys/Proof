Questions, answered

Is Proof free for students?

Yes. Students build and share profiles at no cost. Recruiters and colleges pay for search and placement tools.

Can someone fake a verified project?

Questions come from your own code and commit history, so only the person who built it can answer them well. Every score links to its evidence.

Which projects can I add?

Any project in a GitHub repo you choose, in any language. Live demos make your proof stronger.

Does Proof read all my repos?

No. Proof only looks at the repositories you pick.
